🏠 Chào mừng đến trang chủ

Đây là demo router đơn giản sử dụng Petite-Vue với định tuyến dựa trên hash.

✨ Tính năng

  • Định tuyến dựa trên hash (#/path)
  • Làm nổi bật liên kết đang hoạt động
  • Tham số định tuyến động
  • Cú pháp Vue 3 (v-if, v-model, @click)

ℹ️ Giới thiệu Demo

Demo này giới thiệu hệ thống định tuyến đơn giản được xây dựng với Petite-Vue.

🔧 Cách hoạt động

Router lắng nghe sự kiện hashchange và cập nhật route hiện tại. Mỗi trang được hiển thị/ẩn bằng directive v-if của Petite-Vue để render hiệu quả.

📦 Công nghệ

  • Petite-Vue v0.4.1 - Tập con Vue 3 chỉ 6KB
  • Hash Router - Tự triển khai
  • File HTML đơn - Không cần build tools

⚠️ Lưu ý về Hash Mode

Hash mode (#/path) là cách duy nhất để routing hoạt động với file HTML đơn (không cần server). Nếu muốn sử dụng History mode (/path không có dấu #), bạn cần:

  • Setup HTTP server (Python, Node.js, hoặc PHP)
  • Chuyển sang History API
  • Config server để fallback về index.html
